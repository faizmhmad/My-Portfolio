# ☕ White Valley Cafe

A modern, responsive café website built using **HTML, CSS, JavaScript, and Bootstrap**.  
White Valley Cafe provides an elegant digital experience where users can explore the menu, search items, add to cart, and simulate payments.

---

## 🚀 Live Preview

> https://white-valley-coffee-cafe.netlify.app/

---

## 📌 Features

- ✨ Attractive welcome screen with login/signup modal  
- 🏠 Responsive homepage with hero section  
- 🍽️ Dynamic food, drinks, desserts & bestseller menus  
- 🔍 Smart search functionality across products  
- 🛒 Add-to-cart with live cart badge  
- 💳 Interactive payment page  
- ⭐ Customer reviews section  
- 📱 Fully responsive (mobile, tablet, desktop)  
- 🎨 Modern UI using Bootstrap 5

## 🧠 How It Works

- The website uses a centralized **product database** in `search.js` for search and menu rendering.
- Bootstrap is used for responsive layout and components across pages.
- Users can:
  - Browse categories  
  - Search products  
  - Add/remove items from cart  
  - Proceed to payment
